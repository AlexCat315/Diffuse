# Diffuse 桌面插件平台

本规格替代旧的 Embedded Swift / Wasm 插件方案。编辑器支持 macOS、Windows、Linux。插件作者统一使用 TypeScript，执行运行时统一为 Bun。游戏导出目标与编辑器插件支持范围分别管理。

## 边界

原生宿主保留窗口、渲染、项目实例、贡献注册、进程管理，以及文件/场景修改的事务与确认机制。插件拥有其功能逻辑、视图、服务、扩展点和后台工作。官方插件与第三方包使用相同公开契约。插件不能通过声明一个宿主内置 AI 视图取得实现；面板必须由自己的入口返回组件树。

Bun 以可信桌面扩展进程运行。声明的权限约束宿主代理接口，不能限制插件直接调用 Bun/Node 文件、进程或网络 API。检查和构建包时不执行插件代码；启用时才执行。运行时采用固定发布版本与校验和；交付不依赖预览编译器。

## 包与 SDK

可执行包包括 `plugin.json`、`plugin.js`、`capabilities.json` 和显式声明的 `resources/`。纯声明包不需要执行文件。

```json
{"runtime":{"engine":"bun","entry":"plugin.js","compatibility":1}}
```

`@diffuse/plugin-sdk` 提供 `definePlugin`、`capability`、`InvocationContext`、`DisposalScope`、`hostJob` 和构建 CLI。插件项目不导入 EditorCore，不需要主仓库。构建器静态提取入口契约，用禁用宏的独立 Bun 进程打包源码；包检查绑定 manifest、代码、契约和资源的哈希。

`capabilities.json` 的输入描述支持 string、bool、number、integer、record、list、optional、enum、oneOf。原生边界与 Bun 边界都校验输入。所有入口返回 JSON。

## 生命周期

- 安装记录元数据；启用注册贡献；激活按事件启动代码。
- 一个插件一个原生 broker / Bun 进程，进程故障不牵连其他插件。
- 模块与 `activate(scope)` 在实例内保持；后台任务不能依附当前所选会话。
- 停用级联撤销依赖插件，注销贡献、视图、宿主作业、进程句柄并调用 `deactivate` / scope 清理；超过清理期限终止进程。
- 一个窗口内已加载项目同步停用插件；桌面窗口使用应用级的随包插件启用偏好。
- 重载使用完整授权指纹；代码或契约变化进入安装审阅。
- 外部包在用户确认后复制到应用存储；应用级清单保存精确授权和启停状态，启动时重新校验。项目授权文件不是自动加载入口。
- 顶层模式拥有中央内容；`inSurface` 指向模式的两侧或底部区域。两侧独立折叠，第三方面板可通过公开服务读取模式上下文。工作台底栏与播放、文件导航控件不进入 AI 模式。

## 公开扩展

| 贡献 | 内容 |
| --- | --- |
| `cove.ui.panel/v1` | 入口提供面板；可声明命名空间内顶层 `surface` |
| `cove.ui.documentView/v1` | 按文件扩展名提供文档视图 |
| 命令、菜单、工具栏 | 通过入口和效果协议交互 |
| 语言、任务、版本控制、主题 | 各领域声明与校验；执行行为仍为 TypeScript |
| `cove.service/v1` | `request:string` → JSON 的跨插件异步服务 |
| `cove.extensionPoint/v1` | 插件自己声明版本化扩展点 |
| `cove.extension/v1` | 第三方向该扩展点提供数据或服务标识 |

服务调用采用 start/poll/cancel 作业协议，作业按调用插件隔离。后台工作用句柄与增量轮询，不能把长模型请求放在一次视图调用里等待。

组件树支持布局、滚动、文本、输入、按钮、选择、表格与折叠；布局和颜色采用公开的语义属性。原生渲染器校验节点深度、数量、尺寸、事件和控制项标识。刷新与输入防抖通过 UI 工作队列唤醒 SDL。进程状态读取不持有等待请求的锁，避免回调 UI 时发生互锁。

## AI 插件

`studio.ai` 自己提供顶层视图、模型配置、协议适配、工具循环和会话存储。核心不实现其 provider-format 分支。

会话由独立 UUID 标识，带可选项目路径。多个项目可各有多个会话，同时存在不绑定项目的独立会话。切换项目或新建会话不清空其他会话；每个会话分别取消、保存草稿与消息。文件按会话原子写入，运行锁防止多个项目宿主覆盖同一会话；跨宿主可发出取消请求，崩溃恢复标记中断。

AI 声明 `studio.ai.providers/v1`、`studio.ai.tools/v1`、`studio.ai.skills/v1`。第三方分别提供流式服务、工具服务、指令或声明资源。AI 停用后这些扩展点及消费界面一起撤下。文本补全通过 `diffuse.ai.completion/v1` 服务交付，编辑器的提交信息生成不再自行实现模型请求。

AI 的插件开发工具读取随应用携带的 SDK，写入自己的开发目录，构建包，打开通用安装审阅。构建不会启用包；只有用户启用后才执行包代码。

## 验证与文档

`cove studio plugins prepare` 准备固定版本 Bun、SDK 构建工具和随包插件。`verify` 检查校验和、类型与 Bun 测试。Engine / Editor 测试覆盖契约、授权、生命周期、跨进程回调、工作台贡献与现有功能迁移。Website 提供独立开发、服务/AI 扩展和会话工作流文档。
