# 几何创作基础

`AssetPipeline` 现在同时支持导入网格和保留建模过程的原生 `.dmesh` 资产。控制网格保存共享顶点、多边形、逐角 UV 与材质槽；只有求值结果转换成现有的 24-float GPU 顶点格式。改变修改器参数不覆盖控制网格。

## 本轮可用能力

| 路径 | 实现 |
| --- | --- |
| 多边形 | `PolygonMesh`、选中顶点的仿射变换、单面/区域挤出、保持原形的面细分、显式三角化、子元素删除、共面边溶解 |
| 参数化源 | 立方体、XZ 网格，可配置尺寸与网格分段 |
| 曲线 | 三次贝塞尔样条、绝对坐标手柄、开闭曲线、管状扫掠与端盖 |
| 修改器 | 镜像、阵列、Catmull–Clark 细分、实体化；可排序、启停和序列化 |
| 表面数据 | 平面/平滑法线、UV 插值与接缝、切线及 handedness、PBR 材质槽 |
| 资产流程 | JSON 原生文件、原子保存、项目扫描、资源导入、重载、GPU 目录更新 |
| 编辑器 | 创建网格/曲线、源参数与手柄检查器、材质参数、修改器添加/启停/排序/应用/删除、视口顶点/边/面编辑、统一撤销与重做 |

曲线使用平行移动标架，闭合曲线会分摊标架闭环误差；沿世界竖直方向扫掠也有稳定标架。曲线 UV 在圆周接缝处按角分离，控制网格保持连接。

## 编辑器操作

1. 选择 **世界 → 添加几何**，创建网格立方体、网格平面或贝塞尔曲线。命令面板也可搜索这些操作。
2. 选中物体后，在检查器的“几何”中修改尺寸、分段、曲线半径/手柄或着色模式；“添加修改器”提供四类修改器。
3. 修改器按显示顺序求值，可启停、上移/下移、删除。“应用至此修改器”把该项及之前的启用项烘焙为控制网格，后续项保留；该操作可撤销。
4. 材质槽支持颜色、金属度和粗糙度。参数提交时验证并原子保存到 `Assets/Geometry/*.dmesh`，预览和碰撞派生数据随之更新。

几何编辑与物体变换共用 ⌘/Ctrl+Z、重做的时间顺序。撤销几何编辑会同步源文件与碰撞数据；撤销其他场景操作不会带回旧碰撞网格。资源改名后，已有历史继续跟随其稳定网格槽位。若源文件被外部修改，或文本编辑器中有未保存的该文件草稿，冲突编辑会保留原文件和历史，并在控制台报告。

创建命令同时生成可复用资产与场景物体；撤销物体创建保留资源库中的资产。源资产由所有引用它的物体共享。多选检查器不合并这些资产编辑控件。

## 视口控制网格编辑

选中原生几何后，从视口左侧模式菜单选择顶点、边或面，或在视口内按 Tab。参数化源会转换成多边形控制网格，修改器保留，转换可撤销。模式菜单选择“物体”或再次按 Tab 返回物体模式。

- 模式菜单（键盘 1/2/3）选择顶点、边、面。点击拾取、Shift/主修饰键增减选择沿用编辑器选择偏好；当前工具菜单合并点选、框选和变换，框选按控制点、边中点或面中心取样。变换设置统一放置本地/世界轴与各类吸附步长。
- 默认拒绝被自身或其他场景网格遮挡的元素；“透视选择”（Alt+Z）允许穿透选择。面对点拾取仍选择最近的控制面，凹多边形不会填满其包围盒。
- 平移、旋转、缩放操纵器围绕选中控制顶点的中心工作，可用本地或世界轴。负缩放和非均匀缩放的物体使用世界/控制空间变换，物体本身的变换不变。检查器也可直接输入选区中心。
- 网格工具菜单提供区域挤出（Shift+E）、细分面与三角化。挤出方向/距离在检查器中设置；相邻面只在区域边界生成侧壁，UV 与材质槽保留。细分面不平滑原顶点，并把共享边的中点插入相邻面以避免 T 形接缝；三角化显式改变控制面的结构。
- 底部区分控制网格与修改器结果的顶点/面数。青色线表示求值后的多边形边界，编辑选择仍作用于控制笼；“将结果转为网格”将修改器结果变成可直接选择的控制网格并移除栈，支持撤销。Catmull–Clark 每级把一个四边面分成四个四边面，GPU 渲染时才三角化，四边面本身不是错误。
- “视图”合并投影、着色、标准视角、辅助显示与渲染质量。原生对象选择用真实几何轮廓高亮；原生网格线框读取求值多边形，不把包围盒或 GPU 三角化对角线当作可编辑拓扑。
- Delete/Backspace 或网格工具中的“删除选中元素”按当前模式删除顶点、边或面。顶点/边删除会移除关联面，所有删除都会清理无面引用的孤立顶点。删除最后一个面保留空 `.dmesh` 资产、物体、材质和修改器；渲染、拾取与碰撞同步清空，撤销/重做恢复对应数据。
- 边模式下可用“溶解边”或 Alt+Delete/Backspace 合并共面面区域。区域必须有单一边界、同一材质，且 UV 连续并能由一个仿射映射表示；带孔、折叠、材质/UV 接缝或会改变 UV 插值的选择会被拒绝，文件和历史保留。相连区域内的内部边一并消除，未选区域保持不变。
- 拖拽期间仅发布内存网格覆盖层；释放时原子提交文件并记录一步历史。Escape、失去焦点或拖拽期间的撤销会取消预览。保存场景会先提交有效的几何拖拽。若文件同时被外部修改，提交失败且不会覆盖外部数据。

改变实体、进入播放或撤销到参数化源时会退出控制网格编辑；外部拓扑变化会清空过期的子元素选择。编辑模式没有选中元素时 Delete 不产生操作；删除整个物体需返回物体模式。

## Swift API

```swift
import AssetPipeline

var control = try GeometryPrimitives.box(size: SIMD3(1, 1, 1))
try control.extrude(face: 3, by: SIMD3(0, 0.5, 0))

let document = GeometryDocument(
    name: "Rounded column",
    source: .polygon(mesh: control),
    modifiers: [
        .init(.subdivision(levels: 2)),
        .init(.array(count: 4, offset: SIMD3(2, 0, 0)))
    ],
    shading: .smooth
)
try document.save(to: projectURL.appendingPathComponent("Assets/Column.dmesh"))
let result = try document.evaluate()
// result.controlMesh: 最终控制拓扑
// result.mesh: 现有渲染器可消费的 MeshAsset
// result.topologySlice: 线框索引到共享位置池的映射
```

`.source` 是原始控制数据；`result.controlMesh` 是按顺序应用所有启用修改器后的结果。编辑方法仅在选择、索引和预算有效时提交；烘焙会进一步拒绝退化或自交多边形。网格槽位和 GPU 资源由原有 `AssetRegistry` / `NativeMeshStore` 管理。

## 原生格式

最小文件：

```json
{
  "version": 1,
  "name": "Cube",
  "source": { "box": { "size": [2, 2, 2] } }
}
```

默认使用平面法线、一个不透明非金属材质、空修改器栈。完整格式使用 Swift Codable 的带标签枚举；向量编码为数组。`source` 支持 `polygon`、`box`、`grid`、`tube`；修改器项包含稳定 `id`、`enabled` 与 `operation`。旧文件可省略 `id`，下次保存会持久化兼容标识。完整可导入示例位于 [examples/GeometryAuthoring](../../examples/GeometryAuthoring/README.md)。

网格多边形包含 `vertices`、`materialIndex` 和可选 `uvs`；`vertices` 指向 `positions` 共享位置池，`uvs` 的长度必须等于多边形角数。文件没有外部依赖，复制和游戏资源打包沿用现有的模型资产流程。重载 `.dmesh` 会重新求值并保留路径对应的 meshIndex。原生几何保留场景尺寸与偏移。

## 当前边界

- 已有控制网格视口拾取、框选、仿射变换、区域挤出、子元素删除和共面边溶解；倒角、顶点溶解、环切、桥接等拓扑工具与节点图编辑器仍待实现。
- 细分和实体化要求一致绕序的流形曲面，可有边界；不支持非流形边或顶点。细分支持 0–6 级，尚无边折痕权重。
- 镜像只焊接反射平面上的顶点，不裁切跨平面的面，也不移除已有的内部封口。阵列生成实际几何，不是渲染实例。
- 实体化按顶点法线对称偏移并封闭边界，不计算尖角的等距交线，也不消除厚壳自交。正厚度是必需的。
- 多边形最多 256 个角，三角化在主轴投影中进行，适合简单多边形；强烈扭曲的面应先拆分。区域挤出不消除整体自交；完整闭合曲面没有边界，指定统一偏移时结果等价于平移该曲面。
- 面细分使用边中点与面中心；中心不能连接全部边的凹面须先三角化，以避免产生重叠面。
- 控制网格目前只存曲面及其顶点，不单独保存松散边/点；空网格的顶点与面数组均为空。删除造成非流形曲面时，要求流形输入的后续修改器可能拒绝该编辑，原资产会保留。
- 选区会编辑原始控制笼；修改器生成的顶点不能直接选择。框选使用元素中心，遮挡判断基于几何三角面，不采样透明贴图。大网格的预览求值与控制笼投影目前在主线程进行。
- 管道使用固定分段采样，不是自适应弧长采样；不消除管道自交，重合采样或尖点会报错。端盖使用同一平滑模式。
- 默认限制为 25 万控制/渲染顶点、100 万多边形角，最多 256 个修改器与材质槽；文件上限 32 MiB。增长检查在分配结果前执行。
- 原生材质当前保存颜色、金属度与粗糙度；纹理节点、纹理绘制、雕刻、元球和几何节点图尚未实现。

## 其余创作能力的推进顺序

现有模块已经提供物理、动画播放、实时渲染、路径追踪、序列与媒体编辑的基础；这不代表与完整 DCC 工作流等价。后续以可操作的端到端能力推进：

| 阶段 | 能力 | 接入点与验收 |
| --- | --- | --- |
| 建模交互 | 顶点/边/面选择、区域挤出、倒角、修改器面板 | 控制网格编辑、撤销事务、选择拾取；保存重开结果一致 |
| 程序化几何 | 带类型端口的 DAG、参数输入、实例化与缓存 | 复用几何源/修改器；检测循环、预算传播与依赖失效 |
| 表面创作 | UV 展开、绘制层、材质节点编译 | 材质槽及切线流；实时与最终渲染使用同一材质定义 |
| 动画创作 | 时间轴关键帧、曲线插值、形态键、IK 与动作混合编辑 | SceneRuntime / ScriptRuntime / SequenceRuntime；时间采样与保存回放一致 |
| 模拟扩展 | 风场与缓存编排、烟火/液体求解器、发丝系统 | 现有物理后端与渲染提取；确定性回放、缓存版本及组合模拟 |
| 后期整合 | 合成图、序列片段效果、追踪与遮罩 | SequenceRuntime / Media / RenderBackend；预览与导出一致 |

这些属于后续实施范围，本轮不以占位接口宣称已经具备。
