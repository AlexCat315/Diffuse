# 完整 DCC 工作流验收

目标：在 Diffuse 中完成几何创作、表面创作、动画绑定、物理模拟、渲染、合成、追踪与视频输出的完整工作流。此目标持续有效；已有模块或单项通过测试均不等同于完整工作流完成。

每条能力必须有实际可用的编辑器入口、可编辑的数据模型、保存/重新打开、适用的撤销/重做、可见结果与相应验证。运行时接口、占位按钮、只读面板或只验证编码解码不能单独作为完成证据。

| 范围 | 必需结果 | 当前证据与缺口 |
| --- | --- | --- |
| 多边形建模 | 顶点/边/面选择、变换、区域挤出、倒角、非破坏性修改器 | 已实现控制笼拾取/框选/X-Ray、世界/本地仿射变换、区域挤出、面细分/三角化及四类修改器；真实求值线框、控制/结果统计和应用修改器入口已接入；倒角、删除/溶解、环切/桥接等完整拓扑工具仍待实现 |
| 曲线与曲面 | 手柄编辑、路径/管道、曲面求值、动画驱动 | 贝塞尔管道求值与参数/手柄检查器已实现；视口手柄交互、曲面与动画驱动待实现 |

## 推进记录

- 2026-10-28：原生 `.dmesh` 控制网格、贝塞尔管道、镜像/阵列/细分/实体化、GPU 网格发布已有实现与相关测试；详见 [GeometryAuthoring](GeometryAuthoring.md)。
- 2026-10-28：加入原生几何创建命令、源参数/材质/曲线手柄检查器、修改器结构编辑和统一历史。`GeometryAuthoringTests` 覆盖文件提交、交错历史、应用修改器、碰撞资源、冲突、资源改名与场景重开；`GeometryInspectorLayoutTests` 通过真实控件事件验证添加、参数输入、删除、撤销及两档宽度布局。`NativeGeometryTests` 验证 Metal 渲染与资源替换。
- 真实窗口验证：通过 `cove run Editor --mac --devtools --no-open` 启动编辑器，命令面板创建原生立方体，在检查器添加细分；确认 `.dmesh` 中产生带标识的修改器，视口显示求值后的造型，并保存场景。相关编辑器核心回归、命令目录、控件交互、引擎资产与 Metal 测试通过；维护性检查通过。
- 2026-10-28：加入控制网格视口编辑与区域挤出、CPU 几何遮挡拾取和内存拖拽预览。`PolygonEditingTests` 覆盖相邻区域侧壁、无用顶点清理、拓扑与预算失败回滚；`MeshPickerTests` 覆盖投影、遮挡、X-Ray、凹面和负缩放；`MeshEditingTests` 覆盖预览/取消/提交、冲突、保存和统一历史；`MeshViewportEditingTests` 从工具栏和指针/键盘事件验证拾取、变换与挤出。`NativeGeometryTests` 用 GPU 回读验证临时预览改变画面、取消后恢复原图。
- 下一项：继续完善拓扑工具，并推进程序化几何图、UV/材质创作及动画创作；曲线视口手柄、雕刻、绑定与其余创作域仍按完整清单验收。

- 2026-10-28：修复原生渲染资源更新后未同步编辑器边线/拾取/包围盒缓存的问题；目录保留求值多边形边界，原生对象高亮使用几何轮廓。新增保持形状的选面细分与显式三角化；视口合并为模式、当前工具、变换设置、上下文网格操作与统一视图菜单，区分控制笼和求值结果，并可一步应用修改器后直接编辑细分面。
